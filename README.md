# Observatório do Futuro Sustentável 🌱

**Observatório do Futuro Sustentável** é um portal interativo que monitora o equilíbrio entre agricultura e meio ambiente.  
O site apresenta dados e indicadores sobre uso do solo, conservação de florestas, produção agrícola e recursos hídricos, promovendo conscientização sobre práticas sustentáveis.

---

## 🔹 Funcionalidades

- Painéis interativos com gráficos sobre:
  - Uso do Solo
  - Conservação de Florestas
  - Produção Agrícola
  - Recursos Hídricos
- Layout responsivo e moderno
- Fácil atualização com dados reais
- Visualização clara de informações ambientais para produtores, estudantes e pesquisadores

---

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura do site
- **CSS3** – Estilização e layout responsivo
- **JavaScript (ES6)** – Interatividade e gráficos
- **Chart.js** – Biblioteca de gráficos interativos
